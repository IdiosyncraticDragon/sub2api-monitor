# Sub2API Monitor v0.1.10

This is the first public release with a validated Android companion-app APK.

## Changes

- Fixed Android Flow state aggregation, server-origin parsing, and Glance Widget API usage so the Android application compiles with the documented toolchain.
- Fixed Room snapshot persistence by declaring its singleton primary key.
- Includes the Android companion app, DeepSeek pay-as-you-go balance display, and hardened same-origin WebView sign-in from the preceding source updates.

## Security Notes

- Android access tokens are encrypted with Android Keystore and are not exposed to the Widget.
- The Android APK is debug-signed for sideload testing. Production Android releases require a separately managed signing key.
- Existing `npm audit` findings, GitHub Actions Node.js 20 runtime deprecation warnings, and unsigned macOS artifacts remain tracked separately.
