# Sub2API Monitor v0.1.8

This release adds the Android companion app to the public project and adds pay-as-you-go balance display for DeepSeek accounts across desktop, Android, and iOS.

## Changes

- Added DeepSeek balance retrieval and presentation, including multi-currency balance details, without treating pay-as-you-go balances as subscription usage windows.
- Added the Android 10+ Compose companion app, including encrypted token storage, WebView sign-in, account and user monitoring, offline widget snapshots, and DeepSeek balance support.
- Hardened Android WebView login by restricting navigation and credential scanning to the configured Sub2API server origin.
- Added a GitHub Actions Android build that runs unit tests and publishes a debug APK for sideloading.

## Security Notes

- Android access tokens are encrypted with Android Keystore and are not exposed to the Widget.
- The Android APK is a debug-signed test artifact. Production Android releases require a separately managed signing key.
- Existing `npm audit` dependency findings and GitHub Actions Node.js 20 runtime deprecation warnings remain tracked separately.
- macOS builds remain Apple Silicon artifacts and are unsigned/unnotarized unless Apple Developer signing secrets are configured.
