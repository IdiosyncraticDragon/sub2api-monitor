# Sub2API Monitor v0.1.7

This release refines account usage windows and the compact monitor presentation.

## Changes

- Updated account usage display to use the current usage-window behavior consistently.
- Refined account cards, account lists, and collapsed views to reflect the selected usage window.
- Added tray usage formatting logic and regression tests.
- Added coverage for the updated credential and compact-view behavior.

## Notes

- Existing `npm audit` dependency findings remain tracked for a future dependency maintenance release.
- GitHub Actions Node.js 20 runtime deprecation warnings remain non-blocking for this release.
- macOS builds are Apple Silicon artifacts and remain unsigned/unnotarized unless Apple Developer signing secrets are configured. If macOS reports the app is damaged, remove the quarantine attribute or use a locally signed build.
