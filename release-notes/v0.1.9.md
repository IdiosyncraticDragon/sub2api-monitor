# Sub2API Monitor v0.1.9

This release completes the first public Android companion app build and retains DeepSeek pay-as-you-go balance display across all supported clients.

## Changes

- Fixed Android Room snapshot persistence by declaring the singleton snapshot primary key.
- Added Android unit-test and debug-APK validation to the release workflow.
- Includes the Android companion app and DeepSeek balance display introduced in the preceding public source update.

## Security Notes

- Android access tokens are encrypted with Android Keystore and are not exposed to the Widget.
- The Android APK is debug-signed for sideload testing. Production Android releases require a separately managed signing key.
- Existing `npm audit` findings, GitHub Actions Node.js 20 runtime deprecation warnings, and unsigned macOS artifacts remain tracked separately.
